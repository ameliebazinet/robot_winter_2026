========== LIBRAIRIE =============
    Pour compiler la librairie, on utilise la commande 
        % make clean && make
        dans le dossier /lib.

========== INSTALLATION DU PROGRAMME =============
    Pour installer le programme dans la mémoire interne du robot, on utilise la commande 
        % make install 
        dans le dossier /app.

========== BYTECODE =============
    Pour convertir le bytecode (programme.txt) en binaire, on utilise la commande
        % progmem -o programme.bin programme.txt
        dans le dossier /app/ecriture.

    On utilise ensuite la commande
        % serieViaUSB -e -f programme.bin
        dans le dossier /app/ecriture pour envoyer ce fichier binaire dans la mémoire EEPROM externe du robot.

LEGENDE :
D1..D5    : Capteurs de ligne
IR        : Capteur infrarouge 
DIR G/D   : Direction du moteur (gauche/droite)
PWM G/D   : Vitesse du moteur (gauche/droite, OC0A/OC0B) 
DEL +/-   : DEL (Cathode / Anode) 
P.GND     : GND de la cellule piézoélectrique 
P.SIG     : Signal pour la cellule piézoélectrique (OC1A) 
T         : Minuterie CTC (interruption interne)
PG        : SPI (Programmeur)
SCL/SDA   : EEPROM externe
RXD/TXD   : UART (debug)
B-INT0    : Bouton (interruption externe)
