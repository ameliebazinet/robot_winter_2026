on utilise la commande  
    % make clean && make
dans notre librairie dans le dossier /lib, on utilise la commande 
    % make install 
notre programme main dans le dossier /app vers la mémoire interne 
puis on convertit le programme bytecode (.txt) en bianaire  avec la commande 
    % progmem -o programme.bin programme.txt
puis en utilisant
    % serieviausb -e -f 
on transfère ce binaire dans la mémoire EEPROM externe du robot.
